## Публикация и проверка

Хостинг сайта — отдельный сервер, а не GitHub Pages. Публикация выполнена через FTPS с проверкой сертификата (`server275.hosting.reg.ru`, каталог `/www/bulatny.ru`). Сначала загружены видео и постер, затем CSS и HTML; каждый файл загружался под временным именем, проверялся по размеру и переименовывался. Секреты в репозитории не сохранять.

До публикации все 18 заменяемых файлов совпали с исходным checkout; резервные копии текущего запуска находятся в `/private/tmp/massage-update-20261026/backup` (временное хранение). После публикации все 20 файлов скачаны по HTTPS и совпали с локальными SHA256. Для видео подтверждены MIME `video/mp4` и HTTP 206 с корректным Content-Range. Полное декодирование подготовленного MP4 прошло без ошибок.

В настоящем браузере подтверждены новый четвёртый урок, описание, противопоказания, запуск и перемотка видео на опубликованном сайте. Скриншот: `paid/tmp/2026-10-26-live-ball-lesson.png`. На физическом iPhone/Android не проверялось. Оплата не совершалась; проверена опубликованная страница выдачи, а не новая покупка через Робокассу.
